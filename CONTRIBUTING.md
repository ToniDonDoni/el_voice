# Contributing

## Language

- Write all source code comments in English.
- Write all project documentation in English.
- Write commit messages in English.

## Naming

- Use lowercase `snake_case` for directory names, such as `voice_models/`.
- Use uppercase `UPPER_SNAKE_CASE` for Markdown file names, with a lowercase `.md` extension, such as `CONTRIBUTING.md` or `VOICE_SETUP.md`.
- Keep established conventional names such as `README.md` and `AGENTS.md`.
